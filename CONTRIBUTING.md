# Contributing to football-shorts-autopilot

Thanks for helping. Small, focused PRs get merged fastest.

## Setup

```bash
git clone https://github.com/shauryalowkeygotaura/football-shorts-autopilot
cd football-shorts-autopilot
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and fill in your own keys. Never commit real keys.

## Before you open a PR

```bash
pytest -q
```

- One change per PR. Say what it fixes and how you tested it.
- Keep the existing code style. No new dependencies without a reason in the PR description.
- New behaviour comes with a test where the repo has tests.

## Where to start

Issues labelled [good first issue](https://github.com/shauryalowkeygotaura/football-shorts-autopilot/labels/good%20first%20issue) are scoped for a first PR. Questions go in [Discussions](https://github.com/shauryalowkeygotaura/football-shorts-autopilot/discussions).
